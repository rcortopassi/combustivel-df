# Painel de combustivel de Brasilia

Coleta horaria de precos de gasolina comum e aditivada, posto a posto, na
regiao central sul de Brasilia (fonte: Levantamento de Precos da ANP) e da
parcela Petrobras de refinaria no DF. Publica em
https://rafaelcortopassi.pythonanywhere.com/combustivel/

A copia canonica do codigo vive na pasta do Google Drive do dono; este
repositorio existe para o GitHub Actions rodar a coleta de hora em hora.
